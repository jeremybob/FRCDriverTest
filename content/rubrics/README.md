# Core rubric 1.0.0 — provisional

`core-v1.ts` publishes the six weight/anchor tables from specification §§11–12. Anchors are fixed development criteria, not percentiles, calibrated standards, or real-robot predictions. Current fixture profiles share the published initial anchors but remain separate comparison groups; sharing anchors does not establish equivalence.

All raw distances are meters, durations seconds, heading errors degrees. Lower is better. Normalize with `100 * clamp((weak - value) / (weak - good), 0, 1)`, weight at full precision, then subtract `min(40, 4*minorContacts + 12*majorContacts + 8*boundaryDepartures)`. Round only for display. Missing or nonfinite required metrics yield no computed score, never a perfect score.

Completed attempts use their component breakdown. DNF is zero and occupies its scheduled trial slot. Technical invalidations and practice have null scores and are excluded. Screening requires one scored outcome per skill, remains preliminary, and omits Core index/repeatability. Full assessment requires scheduled slots 1–3 for all six tests, takes each skill median, averages the six medians for Core index, and computes repeatability separately as `clamp(100 − 2*mean(skill ranges), 0, 100)`. Duplicate scored slots do not replace earlier poor outcomes. Profile hashes must match. Aggregation consumes one driver's attempts; roster/report callers filter driver identity first. Historical aggregation uses frozen attempt scores so later rubric changes cannot silently rescore a report.

Contact episodes are per obstacle ID, include maximum closing speed, and rearm after 0.30 s of continuous separation. The same pause applies to corridor return. Floor/support contacts are excluded; wall contacts suppress a coincident boundary penalty. A starting overlap is technical invalidation. A marked corridor departure uses all four bumper corners, and leaving the arena is DNF.

T01 center/heading errors use the final quarter-second of each completed dwell. T02/T03 path RMS samples every 0.05 m traveled against only the ordered active route stage; the far slalom turn pocket is part of its published stage. T04 offsets are robot-center lateral position at the gate plane, accepted only after the entire bumper passes legally. T05 center-plane entry speed must be in band; the first qualifying dwell determines signed front-bumper stopping error. T06 timestamps use milliseconds from one monotonic browser clock; a rendered cue must be acknowledged explicitly before response timing begins. Preheld cue-consistent commands must release before responding. Cue latency itself is stored in seconds.
